# GrowthHUB

Sistema web responsivo baseado no material de design fornecido no App.zip.

## Executar

```bash
npm install
npm run dev
```

Depois abra o endereço indicado pelo Vite.

## Produção

```bash
npm run build
npm run preview
```

## Incluído

- Dashboard responsivo
- Estudos
- Hábitos com persistência local
- Metas com criação rápida
- Reflexões com salvamento local
- Estatísticas
- Perfil
- Tema claro/escuro
- Navegação desktop e mobile
- PWA-ready como base de frontend
- Design system GrowthHUB em branco/navy
